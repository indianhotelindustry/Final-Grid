Channel Manager Integration Guide
Webhook Payload Format (JSON POST) 
{
  "event": "new_booking",
  "source": "booking.com",
  "ota_booking_id": "BDC-123456",
  "room_type_name": "Standard",
  "arrival_date": "2026-03-15",
  "departure_date": "2026-03-17",
  "adults": 2,
  "children": 0,
  "rate_per_night": 1500.00,
  "guest": {
    "name": "Guest Name",
    "phone": "9999999999",
    "email": "guest@example.com"
  },
  "special_requests": "Early check-in"
}
Supported Events
  • new_booking — Creates a Confirmed reservation
  • cancel_booking — Cancels by ota_booking_id
  • modify_booking — Updates dates/rate/pax
Required Headers
  • X-API-Key: <your-api-key>
  • Content-Type: application/json
Optional HMAC Verification
  • X-Signature-SHA256: sha256=<hex>
Test Connectivity
  • GET /webhook/ping — returns {"status":"ok"}
