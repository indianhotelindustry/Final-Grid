LAN Access

Back to Masters

By default the PMS is reachable only on http://localhost:{{ port }} from this machine. Enable LAN access to make it reachable from other machines on the hotel network — front desk, housekeeping, and manager can then all connect to one install.

  • Requires a restart of the PMS server for the binding to change.
  • Also requires an inbound Windows Firewall rule on TCP port {{ port }}. Run enable_lan.bat (as admin) — it writes the rule for you.
  • SQLite serialises writes at the DB level; small hotels (≤ 5 concurrent users) work fine. For heavier concurrent write load, move to PostgreSQL.
