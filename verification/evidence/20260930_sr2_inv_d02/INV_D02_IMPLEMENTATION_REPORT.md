## 1. Rule implemented (`verification/invariants/rules_d.py`, INV-D02)

The population is unchanged (Founder answer): `is_correction` / `is_reversal` rows of `payments` and `extra_charges`.

| Row | Compliant when | Otherwise, named failure |
|---|---|---|
| has `corrects_id` | it resolves in the same table **and** the original is on the **same reservation** | "original does not exist"; "original belongs to reservation X" (**new** — cross-reservation references used to pass) |
| payment, `payment_purpose='refund'`, `is_reversal`, not `is_correction`, no `corrects_id` (cancellation refund) | **exactly one** reservation names it as `cancellation_refund_payment_id`; that reservation is the refund's own, is `Cancelled`, has a refund disposition (`refund_full` / `refund_partial`, the only dispositions `post_cancellation_disposition` refunds on), and recorded this refund's amount in `cancellation_amount_refunded` | "no cancellation names this refund"; "N reservations name this refund"; "reservation X names it but the refund belongs to Y"; "reservation is ⟨status⟩, not Cancelled"; "disposition … generates no refund"; "recorded refund … this row is …" |
| any other flagged row without `corrects_id` | never | "corrects_id is NULL" |

- **Unchanged:** severity CRITICAL, blocking RELEASE, principles, modes and the negative seed (a settlement payment flagged `is_reversal`, which no cancellation names, still fails).
- **Changed:** `reservations` added to `data_sources`; title and rule text rewritten to SR2-RULE.

**Operationalisations for confirmation.** SR2-RULE says "the cancellation itself is a valid, identifiable transaction and the refund is the refund generated by that cancellation". I implemented that as: status `Cancelled`, a refund disposition, exactly one naming reservation, the same reservation, and an equal recorded amount. The amount check is corroboration alongside the explicit pointer, never lineage on its own. One consequence: a reservation that is later re-instated (no longer `Cancelled`) would make its refund fail.
