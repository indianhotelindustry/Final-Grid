{# ── Step 1: Backup ───────────────────────────────────────── #}
1 Take a Backup First

A snapshot of your entire database is saved to the backups/ folder. A backup is also taken automatically when you apply an update, but it is good practice to take one manually before major changes.

{# ── Step 2: Apply update ─────────────────────────────────── #}
2 Upload Update Package

Upload the .zip file sent by your developer. The system will automatically:

  • Take a backup of your database
  • Extract new code (.env, uploads, and backups are never touched)
  • Apply any new database changes
  • Bump the browser cache so staff see the new version immediately
  • Restart the server — staff are reconnected in ~10 seconds
All staff will be briefly disconnected (~10 seconds) while the server restarts. Do this during a quiet period.
Only .zip files from your developer are accepted.
