# PWA Icons

Place your app icons here:

- icon-192.png (192x192 pixels)
- icon-512.png (512x512 pixels)

You can generate these icons from your hotel logo using online tools like:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

For now, you can use any PNG images with the hotel logo or initials.

Recommended design:
- Simple, recognizable icon
- Hotel name initials or logo
- Solid background color (matching theme color #0d6efd)
- High contrast for visibility
